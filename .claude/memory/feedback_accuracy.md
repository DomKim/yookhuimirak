유저 평가: 정확도 체감 40%. "툭하면 까먹고, 뒤돌면 바로 잊는다"

주요 누락 패턴:
- PSD 작은 장식 요소 (점, 선, 아이콘, 구분자)
- 미세 간격 (padding/margin 대충 넘김)
- hover/상태 변화
- 그림자/그라데이션 디테일
- letter-spacing, line-height
- 반복 요소 간 미묘한 차이를 같게 처리
- 유저가 직전에 한 말을 바로 잊음

**Why:** 컨텍스트가 길어지면 앞 내용이 잘리고, 세션 바뀌면 리셋됨. 메모리에 명시 저장하지 않은 지시는 증발함.

**How to apply:**
1. 유저 지시는 즉시 메모리에 저장 — "나중에"는 없다
2. 코딩 전 PSD 수치를 체크리스트로 정리하고 하나씩 소거
3. 완료 선언 전 누락 체크 필수 — "다 했다"고 말하기 전에 원본 재대조
4. 대화 중 유저가 한 말을 반복 확인하는 습관
5. 파일/문서 작성 시: 모든 내용 포함, 누락 없이, 간결하고 클린하게 유지
6. 산발적으로 파일 만들지 말 것 — 중복 없이, 한 곳에 정리
7. MCP 서버 등 외부 도구 연동 시: 반드시 wrapper 스크립트 + 테스트 통과 확인 후 settings.json에 추가. 한번에 끝낼 것. 3번 시도하게 만들지 말 것.
