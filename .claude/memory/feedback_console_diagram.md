description: 섹션 플랜 제출 시 ASCII 콘솔 그림(레이아웃 다이어그램) 절대 빠뜨리지 말 것
type: feedback
---

플랜을 유저에게 컨펌 받을 때 반드시 **콘솔 ASCII 레이아웃 다이어그램**을 포함해야 한다.

**Why:** 유저는 시각적으로 구조를 확인해야 판단할 수 있다. 텍스트 수치 표만으로는 레이아웃 감각을 잡을 수 없다. 여러 번 누락해서 유저가 "영영 안 까먹게 해줘"라고 강조.

**How to apply:**
- 섹션 플랜 제출 시 **구조 트리 + 수치 표 + 콘솔 다이어그램** 3종 세트 필수
- 다이어그램에는: section 경계, inner 컨테이너, 각 요소 위치, padding/margin 화살표(↕), 주요 수치(vw) 표기
- 절대 생략하지 말 것 — 이건 선택이 아니라 필수
