FTP 업로드 전 반드시 현재 작업 디렉토리(pwd) 확인하고, 업로드할 파일 목록을 유저에게 보여준 후 승인받고 진행할 것.

**Why:** 2026-03-27 커넥타 FTP 업로드 시 pwd가 프로젝트모음/으로 빠져서 전체 프로젝트(6개+)를 서버에 올림. 몇 시간 낭비.

**How to apply:**
1. 업로드 직전 `pwd` 출력
2. `find . -maxdepth 1` 결과 유저에게 보여주기
3. 승인 후 업로드
4. 업로드 중 경로 이탈 방지 (절대경로 사용)
