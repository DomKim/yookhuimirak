absol로 배치하기 전에 "이 요소가 rltv 높이체인에 들어갈 수 있는가?" 반드시 먼저 확인.

**How to apply:**
- 다른 요소와 겹치지 않고, 흐름상 순서가 맞으면 → rltv
- 흩어진 장식/사진처럼 콘텐츠 흐름 밖이면 → absol
- 판단 기준: "이걸 rltv로 넣으면 높이체인이 자연스러운가?"
